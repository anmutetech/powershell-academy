# Day 2 — Exercises

## Exercise 1: Variable Types
Create one variable of each type: string, integer, double, boolean, datetime, array, and hashtable. Display each variable's value and its type using `.GetType().Name`.

## Exercise 2: Server Array
Create an array of 5 server names. Then: add a new server, check if "db01" exists in the array, remove the third element (hint: use array filtering), and display the final count.

## Exercise 3: User Hashtable
Create a hashtable representing a user with keys: Name, Email, Department, Role, Active (boolean), StartDate. Display each property on its own line formatted as "Key: Value".

## Exercise 4: Comparison Expressions
Write expressions that answer these questions:
- Is the number 42 between 1 and 100 (inclusive)?
- Does the string "admin@company.com" contain an "@" sign?
- Is "PowerShell" like "Power*"?
- Is 15 divisible by 3 (hint: use modulus `%`)?

## Exercise 5: Name Splitter
Given the string `"John Michael Smith"`, split it into three separate variables: `$firstName`, `$middleName`, `$lastName`. Then display: "Last: Smith, First: John, Middle: Michael".
