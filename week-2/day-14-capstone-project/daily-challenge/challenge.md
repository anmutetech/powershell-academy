# Day 14 — Final Capstone: Enterprise Infrastructure Automation Platform

## Overview

Build a complete PowerShell module called `EnterpriseTools` that an IT team would actually use.

See the main README.md for full requirements and grading rubric.

## Time Estimate

2-4 hours for a complete implementation. Start with one function and build out.

## Quick Start

1. Run `starter.ps1` to create the module skeleton
2. Implement functions one at a time
3. Write Pester tests alongside each function
4. Test the module by importing it and running functions
5. Create the CI workflow last

## Minimum Viable Product

If time is limited, focus on:
1. Module structure (manifest + loader) — 10 min
2. `Get-InfrastructureHealth` with tests — 30 min
3. `Invoke-SecurityAudit` with tests — 30 min
4. `Export-DashboardReport` — 20 min

That gets you 60+ points and demonstrates core skills.
